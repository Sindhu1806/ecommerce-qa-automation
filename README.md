# E-commerce QA Automation

UI automation project using JavaScript and Playwright.

## Technologies
- JavaScript
- Playwright
- Node.js
- Page Object Model

## Test Scenarios
- Login validation
- Product listing
- Add and remove cart items
- Checkout validation
- Cross-browser testing

## Run Tests
npm install
npx playwright install
npx playwright test
